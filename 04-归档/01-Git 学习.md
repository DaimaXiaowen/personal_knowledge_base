# Git 学习

创建：2026-10-23

## 目标

掌握 Git 的日常使用：能独立完成本地版本管理、分支操作与远程协作，理解背后的模型而不只是背命令。

完成的判定标准：

- 能不看笔记完成「改代码 → 提交 → 推送 → 拉取合并」的日常循环
- 理解工作区 / 暂存区 / 版本库的关系，会用 restore、reset、stash 处理误操作
- 能独立发起并合并一次 Pull Request，解决常见的合并冲突

## 计划

分三个阶段，每天 30~60 分钟：

1. **基础概念与本地操作**（第 1 周）：Git 是什么、三大区域、add / commit / log / diff
2. **分支与合并**（第 2 周）：branch、switch、merge、冲突处理，初步了解 rebase
3. **远程协作**（第 3 周）：clone、remote、push / pull、团队协作中的 PR 流程

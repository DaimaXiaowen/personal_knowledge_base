# Git 基础概念

## 来源

## 核心内容

### Git 是什么

Git 是**分布式**版本控制系统：每次克隆都是完整仓库（含全部历史），离线也能提交，提交是本地操作；这是它与 SVN 等集中式系统最本质的区别。

### 三大区域

| 区域 | 是什么 | 进入方式 |
|---|---|---|
| 工作区 | 正在编辑的文件目录 | — |
| 暂存区（Index） | 「下一次提交」的准备清单 | `git add` |
| 版本库（Repository） | 永久保存的提交历史 | `git commit` |

日常循环：**编辑 → `git add`（挑选改动进暂存区）→ `git commit`（生成快照）**。暂存区的价值在于可以把改动拆成多次干净的提交。

### 存储的是快照而非差异

Git 每次提交存储整个项目树快照，未变化的文件以引用复用而非重新存储——这是 Git 分支轻量、绝大多数操作快速的根源。分支本质上只是一个指向某次提交的可移动指针。

### 文件的四种状态

- **Untracked**：新文件，Git 还没有纳入管理
- **Unmodified**：与上次提交一致
- **Modified**：跟踪过的文件发生了改动
- **Staged**：改动已被 `git add` 放入暂存区

状态随 add / commit 流转，`git status` 随时查看。

# learngitbranching

## 链接

- 主站（浏览器直接打开，无需安装）：https://learngitbranching.js.org
- 开源仓库：https://github.com/pcottle/learnGitBranching

## 收藏理由

- 交互式 Git 分支可视化练习场：左侧实时绘制提交树，输入真实 git 命令看分支图变化，把「分支即指针」变成看得见的东西
- 内置关卡体系：基础（add / commit / branch / merge）→ 远程（模拟 origin 的 push / pull / fetch）→ 进阶（rebase -i、cherry-pick、tag 等）
- 适合刚学 Git、需要「看见」分支模型的人；「Git 学习」项目三个阶段都有对应关卡（见 [[01-Git 学习]]）
- 想拿到：分支与远程操作的肌肉记忆；以后深入 rebase -i、cherry-pick 时回来刷进阶关卡

## 使用记录

- 2026-10-23 完成入门关卡（「Git 学习」项目第一阶段）。配合 [[01-Git 基础概念]]、[[03-Git 分支与合并]] 一起用效果最好，最直观的收获是亲眼看到 merge 与 rebase 对提交树的不同改变。评价：强烈推荐，基础 + 远程两套关卡足够覆盖日常场景。

# 06-模板

存放 Obsidian 笔记模板。模板文件夹位置已在 `.obsidian/templates.json` 中配置为 `06-模板`；如需调整，在 Obsidian「设置 → 核心插件 → 模板」中修改。

## 模板列表

- [[01-项目模板]]：立项用，含目标 / 计划 / 任务清单 / 记录 / 复盘，用于 `01-项目`
- [[02-学习笔记模板]]：读书、课程、文章的学习记录，用于 `03-资源/01-读书与学习笔记`
- [[03-资源收藏模板]]：收藏链接、工具、教程，用于 `03-资源/02-资源收藏`

## 使用方式

新建笔记后，通过命令面板（Cmd+P）执行「模板：插入模板」选择对应模板。模板中的 `{{date}}` 会自动替换为当天日期，`{{title}}` 替换为笔记名；引用块里的灰色文字是填写指引，写入内容时直接替换掉。

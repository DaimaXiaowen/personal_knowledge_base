# 个人知识库

基于 PARA 方法组织的 Obsidian 知识库。

## 目录约定

- 同级目录与目录下的文件均使用两位数字前缀命名（如 `01-`、`02-`），保证按名称排序即为阅读顺序
- 每个目录下放置一个 `_<目录名>_index.md`（如 `01-项目` 目录下的 `_01-项目_index.md`），说明该目录的用途与当前目录结构

## 目录说明

- **01-项目**：有明确目标和截止日期的事项，完成后移入 04-归档
- **02-领域**：需要长期维护的方面（如职业发展、健康管理）
- **03-资源**：感兴趣的主题资料
	- 01-读书与学习笔记
	- 02-资源收藏
- **04-归档**：不再活跃的项目和内容
- **05-AI缓存**：AI 自主操作时的临时文件目录，可随时清空
- **06-模板**：Obsidian 笔记模板
- **99-附件**：图片等粘贴附件的统一存放目录

## 使用

用 Obsidian 将本文件夹作为仓库（Vault）打开即可。全库导航入口为根目录的 `_主地图_index.md`，各目录的用途与结构见其中的 `_<目录名>_index.md`。
